预习笔记

结论 · 术语 · 两类误判 · 来源

一、这页在解决什么

预习目标不是背下商详页有哪些模块，而是回答：当 AI 要判断「商家宣传」和「商品实际」是否对得上时，页面上哪些组件能当证据、哪些不能。项目里出现的两类错误，都能在信息载体上找到对应的位置。

二、四条结论

  • 取证通道错配 → 漏放。参数造假发生在结构化事实区（规格参数表、已选 SKU），审核规则却常盯极限词／绝对化用语。商品一个「最」字没说，128G 写成 256G、三级能效写成一级，文本完全合规、事实却是造假。
  • 语用类型误判 → 误杀。「Pro 再超前」「景深效果超惊艳」「如丝般顺滑」是体验修辞，不可证伪；当成可核验事实去判，就会把正常营销话术误判成欺诈。
  • 大量硬参数只存在于图片里。本页「4800 万像素融合式主摄」「A20 Pro 2 纳米制程 / 7 核图形处理器」都写在详情长图上，而规格参数表只列到品牌、编号、系统、机型。只取结构化字段或只查文本，这两处宣称就整体落在取证范围之外。
  • 矛盾藏在字段之间，不在单个字段里。店铺公告图写「全新未拆封 · 全国联保」，常见问题却写「二手商品的来源是什么」，服务承诺行同时出现「免费上门退换」与「不支持 7 天无理由退货」。单看每处都不一定违规，交叉比对才露馅。

四、说明卡分级依据

A 类（蓝色，五层）：模块本身承载或转述商品信息，因此展开「名称 / 功能作用 / 承载什么信息 / 可核验性 / 取证建议与误判风险」。
B 类（灰色，两层）：模块只是导航、操作或跳转，不承载商品事实，只给名称与功能，避免把交互控件也算进证据范围。

五、术语

术语含义
SPU / SKUSPU 是商品聚合信息的最小单位（如某机型）；SKU 是库存最小单元，由颜色、容量、尺寸等销售属性组合而成，下单时点选。
类目属性 / 必填项商家发布商品时按类目填写的结构化字段；不同类目必填项不同，平台接口用 true 标识必填。
京东价 / 划线价 / 到手价京东价为销售价；划线价是参考价并非原价；预估到手价是在标价基础上扣减折扣、券、红包后的估算，页面已声明会因登录态与优惠差异而变化。
事实型 / 承诺型 / 评价型 / 修辞型本页自用的信息分类：可证伪的客观陈述 / 对服务或时效的保证 / 用户主观判断 / 不可证伪的营销表达。
漏放 / 误杀假阴性（该拦未拦）／假阳性（不该拦却拦了）。

六、可核查来源

  • 京东开放平台 · 商品发布接口 —— 明确「不同类目的商品可能有不同的必填项」，必填项以 true 标识。
  • 京东全球购开放平台 · 商品信息规范总则 —— 类目、品牌、标题、视觉规范、商品属性（完整／规范／准确）、SPU/SKU、价格、发货、售后。
  • 京东商家帮助中心 · 类目资质说明 —— 食品经营许可、出版物经营许可、药品经营许可等在发布商品环节触发校验。
  • 京东 2025 年报点评（分品类收入） —— 电子产品及家用电器 6051 亿元、日用百货 4187 亿元；官方仅披露两大类，无「GMV 前三品类」口径。
